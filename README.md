# Ecommerce API REST

API REST de Ecommerce en desarollo, construido con Spring Boot

## Tecnologias

- Java 21
- Spring Boot 3
- Spring Data JPA / Hibernate
- Spring Security
- Spring Web
- PostgreSQL
- JUnit 5 + AssertJ
- Docker
- Docker Compose

## Funcionalidades actuales

- Gestion de usuarios y autenticacion
- Catalogo de productos
- Carrito de compras
- Sistema de órdenes y pagos
- Reseñas de productos

## Requisitos

Necesitas Docker y Docker-Compose

## Como correr el backend

1. Descarga el repositorio

`git clone https://github.com/pedroalbertoramos31-beep/E-commerce
`

2. Ve a la carpeta

`cd E-commerce
`

3. Ejecuta el backend

`sudo docker compose up -d --build
`

Prueba los endpoints con Swagger: http://localhost:8080/swagger-ui/index.html#/
